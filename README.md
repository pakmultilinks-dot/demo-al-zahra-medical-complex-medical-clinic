# Al Zahra Medical Complex - Free Demo Concept Website

This is a **free demo concept website** for **Al Zahra Medical Complex** (medical clinic), located at 217 Shan Bhatti Rd, Ali Town, Lahore, Pakistan. It was created by a Lahore web designer to show what a professional website for the business could look like, before they order one.

**Important:** This is NOT the business's official website. All contact details, services, and timings shown are illustrative demo content, not verified facts about the business. The phone number +92 300 0000000 is a placeholder demo number.

## What's inside

- Hero with floating info cards and quick-contact pills
- Services grid: General OPD, Lab Tests, X-Ray & Ultrasound, Pharmacy, Vaccination, Mother & Child Care
- Sample weekly OPD timings table
- Appointment request form (demo, no data sent)
- CTA band with call/WhatsApp buttons
- Contact section with address, placeholder phone, map link, callback form

## Run

Open `index.html` in any browser. Fully self-contained: no external images, works offline.
